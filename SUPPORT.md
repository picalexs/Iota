# Support

Use GitHub issues for reproducible application bugs, documentation errors, and
small feature requests.

Include the application version or commit, operating system, Docker version,
the command you ran, and a redacted error message. Remove credentials, tokens,
local paths, database files, and provider job identifiers.

This project supports local development only. It does not provide guaranteed
support for IBM accounts, cloud quotas, provider outages, hardware results,
production deployment, or custom infrastructure.

Use private vulnerability reporting for security issues. Do not post secrets or
private data in an issue.
