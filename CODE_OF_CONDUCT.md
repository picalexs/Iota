# Code of Conduct

## Expected behavior

Contributors must:

- use respectful and inclusive language;
- focus on the technical issue, not the person;
- accept clear and evidence-based review comments;
- protect private data and credentials; and
- follow the project scope and security policy.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, doxxing, credential
disclosure, and deliberate disruption are not allowed.

## Enforcement

Report conduct problems privately to the repository owner through GitHub. The
owner can remove comments, close discussions, restrict participation, or take
other action needed to keep the project safe and useful.
