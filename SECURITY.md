# Security policy

Quantum Simulation Studio is a local development workbench. It is not a
multi-user or public-hosting security product.

## Reporting

Do not report a vulnerability, credential, token, or private data in a public
issue. Use GitHub private vulnerability reporting when it is enabled for this
repository. If that channel is unavailable, contact the repository owner
through a private GitHub message before publication.

Include the affected version or commit, the affected component, a short
reproduction, and the impact. Remove credentials and private data from the
report. Do not test against another person's IBM account or submit remote jobs.

## Supported scope

Report issues in the application source, Docker configuration, dependency
configuration, and repository workflows. The project does not provide a
security guarantee for deployments that expose the API or UI beyond loopback.

## Response

The owner will acknowledge a valid report, assess its impact, and coordinate a
fix or mitigation. Do not disclose a report publicly until the owner confirms
that disclosure is safe.
